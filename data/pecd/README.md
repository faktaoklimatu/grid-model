# PECD data

We use data from the PECD (version v4.x?? for ERAA 2025) preprocessed for the country level.

## Demand estimates

The hourly demand estimates in `PECD-country-demand_national_estimates-*.parquet` were constructed using the [ERAA 2025] demand dataset (post-CfE preliminary) and the `transform_country_demand_estimates.r` R script in this directory.

[ERAA 2025]: https://www.entsoe.eu/eraa/stakeholder-interactions/
